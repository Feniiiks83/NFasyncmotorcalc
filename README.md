# AsyncMotorCalc — Расчет характеристик асинхронных двигателей

Веб-приложение для автоматизированного расчета параметров и построения естественных и искусственных характеристик трехфазных асинхронных двигателей по паспортным данным (курсовая работа, 3 семестр).

## Возможности

- **Калькулятор характеристик (`index.html`)**:
  - Ввод паспортных данных двигателя с валидацией и выбором типовых пресетов серии АИР.
  - Расчет по упрощенной и уточненной формуле Клосса (с учетом коэффициента `a = R1 / R2'`).
  - Построение интерактивных графиков `n(M)`, `M(s)` (включая генераторный и тормозной режимы) и `I(s)`.
  - Таблица расчетных точек, экспорт данных в **CSV**, сохранение графиков в **PNG** и печать отчета в **PDF**.
- **Искусственные характеристики (`modes.html`)**:
  - Моделирование регулирования напряжением, частотой (`U/f = const` и ослабление поля) и добавочным сопротивлением в цепи ротора.
  - Наложение искусственной характеристики на естественную и определение рабочей точки при заданном моменте нагрузки `Mс`.
- **Справочник АИР (`catalog.html`)**:
  - База из 14 типовых двигателей (0.75–30 кВт, 750–3000 об/мин) с поиском, фильтрацией и быстрой передачей в калькулятор.
- **Теория (`theory.html`)**:
  - Сводка всех формул и физических пояснений, использованных в алгоритме.
- **Светлая и темная темы** с сохранением выбора в `localStorage` и автоматической перерисовкой графиков.

## Размещение на GitHub Pages

1. Создайте новый публичный репозиторий на GitHub (например, `async-motor-calc`).
2. Загрузите все файлы из корневой папки проекта в ветку `main` (так, чтобы `index.html` лежал в корне репозитория).
3. Перейдите в **Settings → Pages**.
4. В разделе **Build and deployment → Source** выберите **Deploy from a branch**, затем ветку `main` и папку `/ (root)`, нажмите **Save**.
5. Через 1–2 минуты сайт откроется по адресу `https://<ваш-логин>.github.io/<имя-репозитория>/`.

## Локальный запуск

Проект не требует сборки и локального сервера — достаточно открыть файл `index.html` в любом современном браузере. Для отображения графиков требуется доступ в интернет (загрузка `Chart.js` с CDN).
