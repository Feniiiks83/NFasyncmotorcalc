# AsyncMotorCalc — Расчет характеристик асинхронных двигателей

Веб-приложение для автоматизированного расчета параметров и построения естественных и искусственных характеристик трехфазных асинхронных двигателей по паспортным данным (курсовая работа, 3 семестр).

## Возможности

- **Калькулятор характеристик (`index.html`)**:
  - Ввод паспортных данных двигателя с валидацией и выбором типовых пресетов серии АИР.
  - Расчет по упрощенной и уточненной формуле Клосса (с учетом коэффициента `a = R1 / R2'`).
  - Построение интерактивных графиков `n(M)`, `M(s)` (включая генераторный и тормозной режимы) и `I(s)` с подсказками при наведении.
  - Таблица расчетных точек, экспорт данных в **CSV**, сохранение графиков в **PNG** и векторном **SVG**, а также печать отчета в **PDF**.
- **Искусственные характеристики (`modes.html`)**:
  - Моделирование регулирования напряжением, частотой (`U/f = const` и ослабление поля) и добавочным сопротивлением в цепи ротора.
  - Наложение искусственной характеристики на естественную и определение рабочей точки при заданном моменте нагрузки `Mс`.
- **Справочник АИР (`catalog.html`)**:
  - База из 14 типовых двигателей (0.75–30 кВт, 750–3000 об/мин) с поиском, фильтрацией и быстрой передачей в калькулятор.
- **Теория (`theory.html`)**:
  - Сводка всех формул и физических пояснений, использованных в алгоритме.
- **Полная автономность**:
  - Графики рисуются собственным модулем `js/charts.js` (HTML5 Canvas 2D + экспорт SVG), без внешних CDN — работает и на GitHub Pages, и полностью офлайн.

## Структура проекта

```text
.
├── .nojekyll           # Отключает обработку Jekyll на GitHub Pages
├── index.html          # Главная страница (калькулятор и графики)
├── modes.html          # Искусственные характеристики
├── catalog.html        # Справочник двигателей АИР
├── theory.html         # Теория и методика расчета
├── css/
│   └── style.css       # Общие стили и переменные тем
└── js/
    ├── theme.js        # Переключение темы и палитра графиков
    ├── motors-data.js  # Каталог двигателей серии АИР
    ├── calculator.js   # Математический модуль (формула Клосса, токи, CSV)
    ├── charts.js       # Автономный рендерер графиков (Canvas 2D + PNG/SVG)
    ├── index-page.js   # Логика главной страницы
    ├── modes-page.js   # Логика страницы искусственных характеристик
    └── catalog-page.js # Логика справочника
```

## Размещение на GitHub Pages

1. Загрузите все файлы из архива в корень ветки `main` репозитория.
2. Откройте **Settings → Pages**.
3. В разделе **Source** выберите **Deploy from a branch**, ветку `main` и папку `/ (root)`, нажмите **Save**.
4. Через 1–2 минуты сайт станет доступен по адресу `https://<ваш-логин>.github.io/<имя-репозитория>/`.
