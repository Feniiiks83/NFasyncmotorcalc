Теория и методика инженерного расчета

Математические выражения, используемые в расчетном модуле веб-приложения для построения естественных и искусственных характеристик асинхронного двигателя по паспортным данным.

1. Базовые величины и скольжение

Связь частоты сети, числа полюсов и скорости вращения

n1 = 60 · fp ,  ω0 = π · n130
sн = n1 − nнn1 ,  n(s) = n1 · (1 − s)
  • n1, ω0 — синхронная частота (об/мин) и угловая скорость магнитного поля (рад/с).
  • f, p — частота питающей сети (Гц) и число пар полюсов обмотки статора.
  • sн — номинальное скольжение (обычно 1,5–6% для двигателей средней мощности).

2. Номинальные моменты и токи

Определение силовых и энергетических параметров

Mн = Pн · 1000ωн ≈ 9549 · Pнnн ,  Mк = λm · Mн
Iн = Pн · 1000√3 · Uн · ηн · cos φн ,  Iп = kI · Iн
  • Mн, Mк — номинальный и максимальный (критический) электромагнитные моменты (Н·м).
  • λm — перегрузочная способность (кратность максимального момента).
  • Iн, Iп — номинальный и пусковой фазно-линейные токи статора (А).

3. Формула Клосса (упрощенная и уточненная)

Аналитическая зависимость момента от скольжения

sк = sн · (λm + √(λm² − 1))
M(s) = 2 · Mкs/sк + sк/s   (упрощенная)
M(s) = 2 · Mк · (1 + a · sк)s/sк + sк/s + 2a · sк   (уточненная)
  • Устойчивая ветвь (0 ≤ s ≤ sк): рабочий участок двигателя. При росте нагрузки скорость слегка снижается, а момент растет.
  • Неустойчивая ветвь (sк < s ≤ 1): пусковой участок. Если нагрузка превысит Mк, двигатель опрокидывается и останавливается.
  • Коэффициент a = R1/R2' учитывает активное сопротивление статора (важно для двигателей малой мощности).

4. Искусственные характеристики

Влияние управляющих воздействий на форму кривой n(M)

U ≠ Uн:  Mк' = Mк · (U / Uн)²,  sк' = sк
Rдоб > 0:  sк' = sк · (R2' + Rдоб) / R2',  Mк' = Mк
U/f = const:  n1' = n1 · (f / fн),  Mк' ≈ Mк
  • Снижение напряжения резко уменьшает перегрузочную способность (квадратичная зависимость), поэтому используется в узком диапазоне (например, для вентиляторов).
  • Добавочное сопротивление ротора увеличивает пусковой момент и делает характеристику более мягкой, но увеличивает потери скольжения.
  • Частотное регулирование (U/f = const) — наиболее экономичный способ с сохранением жесткости характеристики.

О проекте и структуре приложения

Приложение реализовано на чистых веб-технологиях (HTML5, CSS3, JavaScript ES6+) с использованием библиотеки Chart.js для интерактивной визуализации. Все вычисления выполняются непосредственно в браузере пользователя, без необходимости серверной части, что позволяет размещать проект на GitHub Pages и открывать локально.
